حل المعادلة في مجموعة الأعداد المركبة:

z² + 3zi = −4

مصدر السؤال
الحل خطوة بخطوة:
  1. ننقل −4 إلى الطرف الأيسر: z² + 3zi + 4 = 0.
  2. نلاحظ أن 4 = −4i²، فتصبح: z² + 3zi − 4i² = 0.
  3. نحلل: (z + 4i)(z − i) = 0.
  4. إذن z = −4i أو z = i.
مجموعة الحل: {−4i, i}
إثرائي — من إعداد Moonjezالفصل الأول: الأعداد المركبة

إذا كان z = 2 − 3i، أوجد مرافق العدد z ثم احسب z + z̄.

الحل:
  1. مرافق العدد المركب نغيّر إشارة الجزء التخيلي، لذلك z̄ = 2 + 3i.
  2. نجمع: z + z̄ = (2 − 3i) + (2 + 3i).
  3. تُلغى الحدود التخيلية، والناتج 4.
الجواب: z̄ = 2 + 3i، و z + z̄ = 4.

أوجد قيمة (1 + i)² واكتب الناتج بالصورة a + bi.

الحل:
  1. (1 + i)² = 1 + 2i + i².
  2. نعوّض i² = −1.
  3. الناتج = 1 + 2i − 1 = 2i.
الجواب: 2i.
